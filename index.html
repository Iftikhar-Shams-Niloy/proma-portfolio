Undergraduate thesis

Universal Photography Suggestion System With AI

  • End-to-end deep learning pipeline that analyzes image composition, orientation and subject positioning to suggest improvements.
  • Best composition classification with EfficientNetB0, lowest orientation MSE with EfficientNetB2, and YOLOv8 subject detection using bounding-box logic on COCO.
  • Outputs camera adjustments such as “move-left”, “zoom-in” and “move-upward”.
  • Python
  • TensorFlow
  • Keras
  • OpenCV
  • YOLOv8
  • CNNs

Datasets: Customized CCIP-Dataset · Modified DRC-D · Microsoft COCO

How the thesis system thinks

Pipeline · 4 stages
  1. 01

    Composition

    EfficientNetB0 delivered the best composition classification result.

  2. 02

    Orientation

    EfficientNetB2 reached the lowest MSE for orientation prediction.

  3. 03

    Subject

    YOLOv8 finds the main subject through bounding-box logic on COCO.

  4. 04

    Suggestion

    “move-left”, “zoom-in”, “move-upward” and other camera adjustments.
